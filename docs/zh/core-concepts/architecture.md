# 系统架构

## 概述

kvcached 作为 LLM 推理引擎（vLLM、SGLang）与 GPU 物理内存之间的**垫片层**运行。它实现了 GPU 内存气球膨胀（Memory Ballooning）机制——一个借鉴自虚拟机管理程序的概念——使多个 LLM 实例之间能够弹性、按需地共享内存。

## 核心设计原则

### 1. 以内存为中心的统一视图

kvcached 的核心洞察是：**GPU 内存是多 LLM 服务中的统一瓶颈**。时间共享（模型换入换出）和空间共享（模型并存）本质上都是内存管理问题：

- **时间共享**关注如何高效交换 LLM 权重
- **空间共享**决定如何在并发模型之间分配 KV 缓存容量

通过将 GPU 内存视为弹性资源（气球膨胀），kvcached 可以在两种共享模式之间流畅切换。

### 2. 虚拟/物理内存解耦

类似于 CPU 操作系统的虚拟内存：

- **虚拟内存**：每个引擎在启动时预留一大段连续虚拟地址空间（无物理成本）
- **物理内存**：2MB GPU 内存页按需分配，惰性映射到虚拟地址

### 3. 透明集成

kvcached 要求**零代码修改**。通过 Autopatch 系统在导入时动态替换内存管理函数，以及弹性张量（eTensor）抽象实现。

## 组件架构

| 组件 | 职责 |
|------|------|
| **Autopatch 系统** | 检测引擎版本，应用版本特定补丁 |
| **KV 缓存管理器** | 将应用语义（token 块、层、注意力头）映射到物理内存页 |
| **虚拟内存管理器 (vmm_ops)** | C++ 扩展，调用 CUDA VMM API 进行页面分配/映射/回收 |
| **控制器和路由器** | OpenAI 兼容前端，请求路由，流量监控，睡眠管理 |

## 与 Prism 的关系

kvcached 是 Prism 系统（OSDI 2026）的**气球驱动（Balloon Driver）**组件。Prism 是一个以内存为中心的 GPU 共享框架，另外还包含负载感知模型放置和松弛度感知请求仲裁。kvcached 可作为独立的弹性内存管理库使用。
